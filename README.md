# VALORANT HUB

Информационный сайт о VALORANT: агенты, карты, оружие, скины и игровые режимы.
Тёмная тема с красными акцентами, адаптивная вёрстка, поиск по сайту, трейлер последнего обновления.
Неофициальный фанатский проект, не связан с Riot Games.

## Страницы
- `index.html` — главная (трейлер обновления, разделы)
- `agents.html` — агенты, фильтр по роли
- `maps.html` — карты
- `weapons.html` — оружие по классам, цены
- `skins.html` — все скины: поиск, оружие, редкость
- `collections.html` — наборы скинов по сериям
- `modes.html` — игровые режимы
- `lore.html` — Lore: обзор и хронология вселенной; подстраницы `lore-agents.html`, `lore-agent.html?a=Имя`, `lore-factions.html`, `lore-relations.html`, `lore-events.html`
- `about.html` — об игре и Riot Games
- `404.html` — страница «не найдено»

## Устройство
- `js/data.js` — **все тексты** (агенты, карты, оружие, режимы). Чтобы что-то добавить, добавьте строку в нужный список.
- `js/lore-data.js` — данные Lore. У каждого факта уровень достоверности: `o` — Riot, `w` — вики/пресса, `t` — теория сообщества. Нет данных — пишем «Нет подтверждённых данных».
- `js/lore.js` — логика страниц Lore.
- `js/main.js` — шапка, подвал, поиск, фильтры, загрузка картинок.
- `css/style.css` — оформление.

## Изображения
По умолчанию картинки подгружаются из открытой базы [valorant-api.com](https://valorant-api.com) и кэшируются в браузере на 24 часа. Скины целиком берутся оттуда же.

Чтобы использовать **свои** файлы (они имеют приоритет), положите `.jpg` в `img/agents/`, `img/maps/` или `img/weapons/`
с именем строчными буквами без пробелов и знаков (`jett.jpg`, `kayo.jpg`, `ascent.jpg`, `vandal.jpg`) и впишите это имя в `localImages` в `js/data.js`:

```js
localImages: { agents: ["jett", "kayo"], maps: ["ascent"], weapons: ["vandal"] }
```

Используйте только материалы, на которые у вас есть права (например, из официального медиа-набора Riot Games).
