# VALORANT HUB

Информационный сайт о VALORANT: агенты, карты, оружие и игровые режимы.
Тёмная тема с красными акцентами, адаптивная вёрстка, поиск по сайту.

## Страницы

- `index.html` — главная
- `agents.html` — агенты (фильтр по роли)
- `maps.html` — карты и актуальная ротация
- `weapons.html` — оружие по классам
- `modes.html` — игровые режимы
- `about.html` — об игре и Riot Games

## Изображения

Официальные изображения Riot Games в репозиторий не включены. Вместо них в карточках стоят
геометрические заглушки. Чтобы добавить картинку, положите файл `.jpg` с именем агента, карты или
оружия (строчными буквами) в нужную папку, и он подставится автоматически:

- `img/agents/jett.jpg`, `img/agents/kayo.jpg`
- `img/maps/ascent.jpg`
- `img/weapons/vandal.jpg`

Используйте только те материалы, на которые у вас есть права (например, из официального медиа-набора Riot Games).

## Публикация

Сайт публикуется через GitHub Pages: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.

Неофициальный фанатский проект. VALORANT является собственностью Riot Games, Inc.
