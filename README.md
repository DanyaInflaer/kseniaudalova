# VALORANT HUB

Информационный сайт об игре VALORANT: агенты, карты, оружие и игровые режимы.
Неофициальный фан-проект, не связан с Riot Games.

## Структура
- `index.html`, `agents.html`, `maps.html`, `weapons.html`, `modes.html`, `about.html` — страницы
- `css/style.css` — оформление
- `js/data.js` — **все данные** (агенты, карты, оружие, режимы) — править здесь
- `js/main.js` — шапка, подвал, поиск, фильтры, подгрузка картинок с valorant-api.com
